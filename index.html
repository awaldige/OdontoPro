SOBRE O PROJETO

Uma loja virtual pensada para simplificar a experiência.

A OdontoPro é um projeto demonstrativo de comércio eletrônico desenvolvido para apresentar uma experiência de navegação e organização de produtos do segmento odontológico.

O projeto reúne catálogo, pesquisa, filtros por categoria, carrinho interativo, checkout simulado e recursos de acessibilidade em uma interface adaptável.

DÚVIDAS FREQUENTES

Perguntas e respostas

Entenda como funciona a demonstração da OdontoPro.

Os produtos estão disponíveis para compra?

Não. Este projeto é exclusivamente demonstrativo. Não há estoque, venda ou comercialização dos produtos.

Os preços apresentados são reais?

Não. Os valores são ilustrativos e servem apenas para demonstrar o funcionamento do catálogo e do carrinho.

Como funciona a finalização da compra?

É possível preencher um nome e e-mail fictícios, selecionar uma forma de pagamento demonstrativa e visualizar uma confirmação de compra simulada. Nenhum pedido real é criado.

Existe pagamento online?

Não. Pix, cartão e boleto são apenas opções ilustrativas. Nenhuma transação financeira é realizada.

Posso utilizar o site pelo celular?

Sim. A interface foi planejada para se adaptar a diferentes tamanhos de tela.
